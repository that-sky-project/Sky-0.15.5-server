## ============ 第 1 段：本包的目标环境 ============
## 部署方式
#   Docker Compose（deploy/docker-compose.yml），三个容器：
#     wbsky       主服务 Flask index.py
#     wbsky-udp   联机房间服 Node sky0155-udp
#     wbsky-ws    聊天 WS 中继 ws_server.py
#   配置入口只有一个：deploy/.env

## 镜像
python:3.10-slim          # 主服务 + 聊天 WS（与老机器 Python 3.10.12 对齐）
node:20                   # 房间服（必须完整版，sky-enet 要现场 node-gyp 编译）

## Python 依赖（deploy/requirements.txt，按第 2 段 pip freeze 钉版本）
Flask==3.1.3

requests==2.34.2

## 端口（老机器 → 本包）
#   TCP 2999 → 2007        主服务（游戏 API + /live 面板 + /admin 后台）
#   UDP 8125 → 19458       联机房间服（**端口变了**，客户端不用改：地址是下发的）
#   TCP 8125 → 11925       房间服 /stats（拆开，只绑 127.0.0.1）
#   TCP 9002 → 2500        聊天 WebSocket（内部管道；客户端连的是主服务 /account/ws，
#                          由 nginx 转给 ws 容器，所以客户端不用改）
#   TCP 520    不变        1Panel 面板
#
#   ★ 容器内外同号：容器里也是 2007 / 19458 / 2500 / 11925，
#     所以 `docker exec` 里自查不用换算，排障手册里的命令可以直接照抄。

## 目标服务器
#   主机/域名 : beta.admin.xyz
#   公网 IPv4 : 103.24.218.98     ← 必须填在 WB_SKY_UDP_HOST，客户端据此联机
#   数据库    : 1Panel 应用商店的 MySQL，库 skygame / 用户 wbsky（库名与账号可以不同名）
#   项目目录  : /opt/1panel/apps/skywb

## 生效中的关键配置（与老机器一致，迁移别丢）

#   udp_debug_gamemsg=false  log_requests=true      use_mysql=true
#   all_user_consumables_count=999   all_user_candles=999
